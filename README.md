# blackantarra
Black Antarra | Cattery of Noble Siamese and Oriental Cats in Estonia.

## Структура

- `index.html` — главная страница (копия `Black Antarra Landing v2.dc.html`)
- `404.html` — страница ошибки (копия `404.dc.html`)
- `support.js` — рантайм страниц
- `_ds/` — дизайн-система (шрифты, токены, компоненты)
- `assets/` — логотипы, иконки, иллюстрации, фото
- `uploads/` — исходные материалы

Сайт статический: можно открыть через любой веб-сервер или GitHub Pages
(файл `.nojekyll` нужен, чтобы папка `_ds` публиковалась).
